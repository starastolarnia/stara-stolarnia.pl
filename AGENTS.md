# Project instructions

## Copy and translations

- Every change to user-facing copy must include a consistency review of all supported language versions: Polish (`content/pl`), English (`content/en`), and German (`content/de`).
- Keep the meaning, facts, calls to action, links, section IDs, content structure, and metadata aligned across translations unless a locale-specific difference is intentional.
- Check interface labels stored outside Markdown content as part of the same review.
- Before completing a copy change, verify that every locale still has the same set of content files and matching frontmatter fields.
